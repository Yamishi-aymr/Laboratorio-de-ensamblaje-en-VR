# Laboratorio VR – Ensamblaje 3D

Aplicación web de realidad virtual desarrollada con **Three.js y WebXR**, que permite manipular y ensamblar cinco piezas tridimensionales mediante seguimiento de manos y gestos de pinza, orientada a Meta Quest 3.

## Objetivo

Desarrollar una experiencia inmersiva en la que el usuario pueda seleccionar, arrastrar y colocar cinco piezas en sus respectivos destinos mediante interacción natural con las manos.

## Características principales

- Escenario tridimensional interactivo.
- Cinco piezas y cinco destinos de ensamblaje.
- Seguimiento de manos mediante WebXR.
- Selección y arrastre mediante gesto de pinza.
- Validación de colocación y ajuste automático (_Snap-to-Target_).
- Efectos visuales y sonidos de retroalimentación.
- Contador de progreso (0/5).
- Cronómetro y sistema de reinicio.
- Salida segura de la experiencia VR.
- Interfaz web responsiva con Bootstrap 5.
